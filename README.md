## 📌 Project Overview
This project was completed as part of the Digital Literacy course. The aim of this project is to understand and apply important digital skills such as creating online profiles, using collaboration tools, practicing coding, communicating professionally, and staying safe from cyber threats.  

The project consists of five tasks, each focusing on a different aspect of digital literacy.

---

## 🟢 Task 1: Digital Literacy Infographic
In this task, I created an infographic using Canva to explain key concepts of digital literacy such as safe internet practices, online presence, and digital tools. The infographic was designed to be visually appealing and easy to understand.
